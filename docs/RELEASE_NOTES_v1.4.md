## CET_Score v1.4

四六级估分助手 —— 输入真实对错情况，算出 710 分制预估总分。

### 1. 历史记录详情现在能看到完整信息

以前点开一条历史记录，只有总分和四个模块分，
看不出当时每个题型对了几题、占分多少。

现在详情面板与估分结果页**完全一致**：

- 预估总分 + 及格线进度条 + 距 425 分差多少
- 各模块得分（听力 / 阅读 / 写作 / 翻译，2×2 卡片）
- 各部分得分占比（环形图 + 图例，含每部分原始分）
- 题组明细（每组答对几题、得几分）
- 备注

数据本来就存在记录里，只是之前没渲染出来。
对早期版本保存的、没有题组明细的记录，会明确提示「该记录未保存明细」，
而不是显示一排 0 分。

### 2. 修复：升级 App 会清空历史记录

**这是本次最重要的修复。**

数据库之前启用了 `fallbackToDestructiveMigration()`：
只要表结构有任何变化，Room 就会直接删库重建。
也就是说，升级一次 App，历史记录就被清空一次。

现在改为显式迁移机制：
- 移除 destructive fallback
- 以后改表结构必须写对应的 `Migration`
- 漏写迁移时构建/升级会直接报错，而不是静默丢数据

已升级过（记录已被清空）的损失无法追回，但从这一版起不会再丢。

### 3. 最多保存 3 套 AI 配置，随时切换

专业模式可以配置多套 AI 接口了，每套包含：

- 配置名称（如「DeepSeek 官方」「学校代理」）
- API Key
- Base URL
- 模型名

设置页顶部点击标签即可切换；「开始 AI 评分」旁边的按钮会显示
当前正在使用哪一套，避免用错模型还不知道。
保存某一套时自动设为当前使用。

### 4. AI 配置也随版本更新保留

配置存在应用私有目录的 SharedPreferences 中，覆盖安装不会丢。
从 v1.3.1 及更早版本升级时，原来的单套配置会**自动迁移**成
「默认配置」放在第一位，不需要重新填写。

> 只有「卸载重装」或「清除应用数据」才会丢失本地配置与历史记录。
