## CET_Score v1.3.1

四六级估分助手 —— 输入真实对错情况，算出 710 分制预估总分。

### 修复：填了题目和作答，AI 却说「尚未提供原文和译文」

**问题**：两种模式都只把评分标准发给了 AI，用户填在「原题目」「我的作答」
里的内容一个字都没出去。AI 收到一套评分标准加空白材料，只能回
「你尚未提供中文原文和英文译文，请按格式补充」。

**原因**：模板组装函数 `PromptAssembler.assemble(模板, 题目, 作答)` 已经写好了，
但两处调用都没用它——
- 专业模式的「开始 AI 评分」直接发送裸模板
- 普通模式的「生成提示词并复制」复制的也是裸模板

**修复**：两处都改为走 `PromptAssembler`，现在发送/复制的内容结构为：

```
{对应级别与题型的完整评分标准}
---
【题目要求/翻译原文】：
{你填的原题目}

【我的作答】：
{你的作文或译文}
```

另外：
- 「开始 AI 评分」按钮现在要求评分模板已加载完成，避免极端情况下发出空模板
- 普通模式的提示词预览、字符数、复制内容三者统一为拼好的完整文本
  （以前预览与复制都是裸模板，看不出少了什么）
