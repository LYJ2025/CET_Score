## CET_Score v1.2

四六级估分助手 —— 输入真实对错情况，算出 710 分制预估总分。

### 功能

- **估分**：按题组输入答对题数，写作/翻译按档位自评，实时估算总分
- **结果**：总分 + 四大模块得分 + 6 部分占比环形图 + 题组明细
- **历史**：备注可编辑、按级别筛选、详情面板
- **趋势**：折线图 + 425 及格线，长备注不撑爆布局
- **AI 评分助手**：替换式三屏导航，四套独立提示词
  - 普通模式：生成提示词并复制，全程不联网
  - 专业模式：直连第三方 AI 接口流式评分（需自行配置 API Key）

### 安装

下载 `CET_Score-v1.2-release.apk` 安装即可。

- minSdk 26（Android 8.0）/ targetSdk 34
- 正式包已签名（v2 + v3 签名方案）
- 体积 1.9 MB（R8 混淆 + 资源压缩）

> ⚠️ 安装时系统会提示「未知来源应用」，这是未上架应用的正常提示。
> 后续升级请使用同一签名，否则需卸载重装。

### 权限说明

仅申请 `INTERNET` 与 `ACCESS_NETWORK_STATE`，**仅专业模式在用户主动点击
「开始 AI 评分」时才会联网**。估分算法、历史记录、趋势图全部本地运行，
数据只存应用私有目录。不申请存储、相机、位置等权限。

### 已知限制

估分基于简化模型，写作与翻译的自评档位由用户判断，结果与官方成绩可能
存在偏差，仅供参考。

完整的评分标准提示词见仓库 `docs/四六级评分标准提示词.docx`。
